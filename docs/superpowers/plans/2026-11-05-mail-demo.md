# Login-free mail demo implementation plan

**Goal:** Issue #1: synthetic mail UI and asynchronous Mock API usable by issue #2.
**Architecture:** Static ES modules load the existing JSON fixtures. A pure Mock adapter owns list/search/pagination and batch tag lookup. A page bridge exposes a versioned postMessage protocol for isolated content scripts. The page renders no tag badges; lookup diagnostics live outside mail rows.
**Tech stack:** HTML/CSS, browser JavaScript, Node.js 22 test runner, Playwright for browser tests. Python's static HTTP server for local use; no application backend or runtime dependencies.
**Spec:** GitHub issue #1, docs/research/demo-input-contract.md, docs/research/naver-webmail-dom.md. User delegates design choices and requests implementation, testing, commit, push and issue comment without another approval step.

## Constraints and design decisions

- Reuse all existing fixtures without exposing real mail or contacting external services.
- IDs are strings. Namespace is part of identity; folder is independent context. Account B is an explicitly empty synthetic account.
- Preserve observed list/link/class hierarchy. Missing, malformed or conflicting IDs are never inferred. Title is text.
- View changes, reset and node reuse increment generation. Request context is captured before awaiting; late diagnostics/bridge responses cannot be applied to new context.
- Fault settings apply only to tag lookups so mail controls remain usable: slow, 401, 403, 500, offline, timeout. Each call snapshots its settings; AbortSignal supports cancellation.
- Considered server endpoints and a service worker: both add lifecycle/setup complexity for this initial fixture-only demo. Choose an importable adapter plus postMessage bridge instead. Neither is an HTTP API or authentication boundary.

## Review focus

- Reject numeric/invalid IDs and malformed batches; preserve arbitrarily long string IDs.
- Deduplicate repeated DOM identities without conflating folder context or ambiguous results.
- Literal HTML-like titles; no injected tags inside mail rows.
- Slow responses crossing search/page/account/reset/reuse boundaries.
- Extension request origin/source validation, correlation and error serialization.
